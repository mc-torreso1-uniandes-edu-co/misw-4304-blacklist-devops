## 2. Decisiones

| Aspecto | Decisión | Motivo |
|---|---|---|
| Origen | CodePipeline | Es la decisión de #93 y #94: el código llega ya descargado de la etapa de origen y el proyecto no necesita acceso propio a GitHub |
| Imagen | Amazon Linux, familia *standard*, versión 6.0 | Es la más reciente de las imágenes de Amazon Linux que ofrece AWS, y el diseño pide una imagen administrada de Amazon Linux |
| Cómputo | El más pequeño | Las pruebas usan SQLite en memoria y el empaquetado es un `.zip` pequeño; no necesitan más |
| Variables de entorno | Ninguna en el proyecto | `APP_ENV=testing` ya está en el `buildspec.yml`, y `COMMIT_ID` lo entrega el pipeline en #103. Así no hay secretos ni configuración repartida |
| Rol | El rol existente de 1.5 | Conserva los permisos mínimos documentados. Con la CLI no se modifica el rol, a diferencia de la opción de la consola que deja a CodeBuild agregarle permisos |
| Modo privilegiado | Desactivado | Solo hace falta para construir imágenes de contenedor, y esta entrega genera un `.zip` |
| Creación | AWS CLI | Es reproducible y queda el comando exacto; las capturas de la consola se tomaron después sobre el proyecto creado |

## 3. Comando de creación

El comando se ejecutó en AWS CloudShell, que usa las credenciales de la sesión de la consola. Para
reproducirlo con la CLI local se agrega `--profile blacklist`.

```bash
aws codebuild create-project \
  --name blacklist-devops-ci-build \
  --source type=CODEPIPELINE \
  --artifacts type=CODEPIPELINE \
  --environment type=LINUX_CONTAINER,computeType=BUILD_GENERAL1_SMALL,image=aws/codebuild/amazonlinux-x86_64-standard:6.0 \
  --service-role arn:aws:iam::253041091381:role/blacklist-devops-codebuild-role \
  --logs-config cloudWatchLogs={status=ENABLED} \
  --region us-east-2
```

El comando solo debe ejecutarse si el proyecto no existe. La creación de recursos de AWS requiere
confirmación humana previa y no debe repetirse sobre el proyecto existente.

## 6. Notas

- **Aviso informativo de la consola.** La página del proyecto muestra un aviso azul que dice que el
  proyecto usa Amazon Linux 2 como sistema operativo anfitrión y recomienda pasar a Amazon Linux 2023. Es
  informativo: CodeBuild indica que seguirá dando soporte a Amazon Linux 2. No es el aviso de
  **características avanzadas** del plan gratuito, que no apareció en ningún paso. La opción *Host kernel*
  quedó con su valor por defecto y no se cambió porque no forma parte del alcance de #99.
- **Python 3.13.** El `buildspec.yml` pide `runtime-versions: python: 3.13`. Todavía no se confirmó que la
  imagen elegida lo ofrezca; se comprobará en la primera ejecución del build, en la fase de instalación. Si
  la imagen no lo ofrece, el plan alterno es la imagen `aws/codebuild/standard:8.0` o instalar Python 3.13 en
  la fase de instalación, y se anotará aquí.
- **Variable `COMMIT_ID`.** El `buildspec.yml` la necesita para la etiqueta del artefacto. No se define en
  el proyecto: la entrega el pipeline en #103 como variable de la acción de construcción.
